# 32-bit Unsigned Divider

This project implements a 32-bit unsigned divider in Verilog HDL using two design approaches:

1. Behavioral Modeling
2. Structural Modeling

Both implementations compute the quotient and remainder of two unsigned 32-bit operands and have been verified through simulation.

## Behavioral Implementation

The behavioral model describes the division algorithm using high-level Verilog constructs and focuses on functionality.

## Structural Implementation

The structural model decomposes the divider into smaller hardware blocks such as datapath and control logic, providing a closer representation of actual hardware architecture.

## Features

- 32-bit unsigned division
- Quotient and remainder generation
- Behavioral and structural RTL implementations
- Testbench verification
- Simulation waveform validation
